# Caderno-Tem-tico---Infraestrutura-de-TI-com-notebooklm
Projeto desenvolvido na DIO utilizando o Google NotebookLM para criar um caderno temático sobre Infraestrutura de TI. O repositório reúne objetivos de estudo, curadoria de fontes, testes de engenharia de prompts, resumos, glossário e um conjunto de prompts reutilizáveis para apoiar revisões e aprendizado contínuo.
